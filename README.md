# Credit-Breton
Source : [OpenClassrooms - Réalisez des dashboards avec Power BI](https://openclassrooms.com/fr/courses/7110891-realisez-des-dashboards-avec-power-bi)

Une banque souhaite améliorer leurs dossiers de demande de prêts.

## L'objectif du projet demandé
Réduire les délais de prise de décision sur l’accord des prêts. Actuellement, les responsables concernés sont soit débordé, soit il prenne une décision sur des critères vagues et oubli des détails
Améliorer la qualité des dossiers de prêt validés. Moins de délais, plus de dossiers traités, plus apte à accompagner les clients dans leur démarche de demande de prêt

Notre cliente est une cheffe de projet de l'entreprise

## Modèle de données
Le modèle de données : Une brève explication des tables et des relations (étoile, flocon...).
Présenté en détails sur le schema-modele.png
On a pris la peine avant publication sur ce dépôt public de retirer les données sensibles.

## Données
Les données exploitées sont présent dans */data* en fichier Excel *.xlsx*

## Installation
Télécharger tout le dépôt. Si les données ne sont pas présent au lancement du fichier Power BI *.pbix*, onglet **Accueil** -> section **Données** -> **Obtenir les données** -> **Classeur Excel**
